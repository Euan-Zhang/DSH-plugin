# 皮肤插件 —— 安装与使用说明

本插件为 DeepSeek Harness（DSH）增加「皮肤」能力：在 **设置页左侧** 新增一个
「皮肤」切换入口，内置「默认皮肤」「黑神话·悟空皮肤」，并支持**导入皮肤文件、
安装新皮肤、一键切换、卸载**。

- 🎨 内置皮肤：默认皮肤（DSH 原生外观）、黑神话·悟空（黑金配色 + 毛玻璃金边 + 悟空官网视频底纹）
- 🔁 一键切换：点「使用」立即生效，刷新后保持
- ➕ 新增皮肤：导入 `.dshskin` 皮肤文件实现安装
- ✅ 严格校验：按《皮肤文件格式规范》逐字段校验，不合规文件被拒绝并给出中文原因
- 🗑️ 卸载：已导入皮肤可一键卸载

> 本质是一个 DSH **双面插件**：host 半部负责皮肤目录、校验、存储与 HTTP API；client 半部负责设置页 UI、主题令牌覆盖、样式与背景注入。不修改 DSH 源码。

---

## 一、交付物

| 文件 | 说明 |
|---|---|
| `dsh-skin-manager-1.0.0.tgz` | 插件压缩包（标准 npm tarball），可在任意 DSH 电脑上安装 |
| `皮肤文件格式规范.md` | 可导入皮肤文件（`.dshskin`）的格式与要求 |
| `examples/` | 三个示例皮肤文件，可直接导入体验 |
| 本说明文档 | 安装与使用指引 |

---

## 二、前置条件

- 已安装并可运行 DeepSeek Harness（Web 版，即 `dsh web` / `--profile web` 启动的界面）。
- 本机 `pnpm` 可用（DSH 的插件安装底层走 pnpm；随 DSH 自带的 pnpm 可直接使用）。

> 说明：插件的 HTTP 接口与资源路由依赖 web 应用层（`webServer` 服务），因此请安装到
> **web profile**（即你平时用浏览器打开的 DSH），而不是 headless/base profile。

---

## 三、安装步骤

### 方式 A：命令行安装（推荐）

1. 把 `dsh-skin-manager-1.0.0.tgz` 复制到目标电脑（任意目录）。

2. 打开终端，执行：

   ```bash
   dsh plugin --profile web add ./dsh-skin-manager-1.0.0.tgz
   ```

   或使用绝对路径：

   ```bash
   dsh plugin --profile web add "C:/path/to/dsh-skin-manager-1.0.0.tgz"
   ```

   > 若 `dsh` 命令不在 PATH 中，可用等价的 node 调用：
   > ```bash
   > node <DSH安装目录>/apps/cli/lib/bin.js plugin --profile web add ./dsh-skin-manager-1.0.0.tgz
   > ```

3. 安装完成后插件会自动写入 web profile 的 bundle 清单。**重启 DSH**（关闭并重新
   启动 `dsh web`，或重启你的 DSH 启动脚本）使插件生效。

4. 重启后，打开 DSH 网页 → 左下角「设置」，左侧导航栏会多出「皮肤」一项。

### 方式 B：图形界面（若你的 DSH 提供插件管理页）

部分 DSH 版本在「设置 → 插件」中提供插件安装入口，可上传 `.tgz` 安装。安装后同样需要
重启 DSH 生效。

---

## 四、验证安装是否成功

重启 DSH 后，打开 **设置** 面板，确认左侧导航包含：

```
通用设置 · 模型 · 插件 · Agent 预设 · 皮肤
```

看到「皮肤」即表示安装成功。进入后应能看到「默认皮肤」「黑神话·悟空」两项。

命令行可进一步验证挂载（可选）：

```bash
dsh web --dump-config | grep -A2 dsh-skin-manager
```

应能看到 `dsh-skin-manager` 行。

---

## 五、使用方法

1. 打开 DSH → 左下角 **设置** → 左侧点选 **「皮肤」**。

2. **切换皮肤**：在皮肤列表点某张皮肤右侧的「使用」，界面立即换肤；当前生效的皮肤
   标「使用中」。

3. **新增皮肤（导入）**：页面底部「新增皮肤」→「选择皮肤文件并安装」→ 选中一个
   `.dshskin` 文件。合法则进入皮肤列表，不合法则显示具体哪一项不合规。

4. **卸载皮肤**：已导入的皮肤显示「卸载」按钮（点两次确认）；内置皮肤不可卸载。

> 皮肤文件的格式与要求见《皮肤文件格式规范.md》；`examples/` 里有三个现成的
> 皮肤文件，可直接拿来导入体验。

---

## 六、数据存储位置

- **已导入皮肤 + 当前选中皮肤**：持久化在 `$DSH_HOME/profiles/skins/`
  （`index.json` 记录选择与已安装清单，每个皮肤一个子目录存放 `manifest.json`）。
- **内置皮肤**（默认、黑神话·悟空）：随插件打包，无需存储。

---

## 七、卸载

```bash
dsh plugin --profile web remove dsh-skin-manager
```

然后重启 DSH。卸载会移除设置页的「皮肤」入口与插件接口；已导入的皮肤数据保留在
`$DSH_HOME/profiles/skins/`，如需彻底清除可手动删除该目录。

---

## 八、常见问题

- **Q：安装后设置页没有「皮肤」？**
  A：需要**重启 DSH**（插件加入 bundle 清单后重启才生效），并确认安装到的是 web
  profile 而不是 base/headless profile。

- **Q：导入皮肤文件提示「id 已存在」？**
  A：皮肤 `id` 不能与内置皮肤（`default`、`wukong`）或已安装皮肤重复。`examples/wukong.dshskin`
  的 id 是 `wukong`，与内置的黑神话皮肤同 id，因此在已装本插件的环境里导入它会被
  拒（这正是校验规则之一）；把文件里 `"id"` 改成别的（如 `"wukong-copy"`）即可导入。

- **Q：导入皮肤文件提示「不是合法的 JSON」？**
  A：皮肤文件必须是 UTF-8 编码的 JSON 文本；确认没被编辑器改成 BOM 或其它编码。

- **Q：视频背景为什么不显示 / 一直加载？**
  A：视频背景需为 `data:video/...` base64 内嵌或可访问的外部 URL；确认地址可访问，
  浏览器也需允许自动播放（DSH 界面内通常已静音自动播放）。

- **Q：和旧皮肤插件（dsh-skin-deepseek / dsh-skin-wukong）冲突？**
  A：这些旧插件是「常驻覆盖」式，会与本插件的切换叠加冲突。建议卸载它们后只用本插件。
